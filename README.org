* jsonparse

=jsonparse= is a strict JSON parser for R6RS Scheme built around a [[https://github.com/Kiyomi-Computation-Systems/byte-machine][push parser]], in the style of C’s [[https://lloyd.github.io/yajl/][YAJL]]. Instead of reading a whole document into a tree, it takes bytes in pieces of any size and calls your procedures as it reads. That lets you parse input as it arrives, or handle a huge document without building it in memory. When you do want a tree, one call gives you plain Scheme values. This makes it very
useful for [[https://github.com/Kiyomi-Computation-Systems/circuit][servers]].

=jsonparse= can read [[https://kiyomi-computation-systems.github.io/jsonparse/easy.html][whole documents or streams]], and has procedures for [[https://kiyomi-computation-systems.github.io/jsonparse/writer.html][writing
JSON]] as well.

** Installing

It needs Chez Scheme 10.4.1 or later. Clone it with its submodule, and put
two folders on the library path:

#+begin_src sh
git clone --recursive https://github.com/Kiyomi-Computation-Systems/jsonparse.git
cd jsonparse
scheme --libdirs src:vendor/byte-machine/src --program app.sps
#+end_src

An [[https://akkuscm.org/][Akku]] package is coming. [[file:docs/installing.md][docs/installing.md]] says more.

** A taste

#+begin_src scheme
(import (rnrs) (jsonparse easy))

(string->json "{\"name\": \"Ada\", \"langs\": [\"en\", \"fr\"]}")
;; => (("name" . "Ada") ("langs" . #("en" "fr")))
(json->string '(("ok" . #t) ("n" . 1.5)))
;; => "{\"ok\":true,\"n\":1.5}"
#+end_src

** Developing

=make help= lists every target. On a Guix host, run them through
=scripts/guix-env=, as in =scripts/guix-env make test=. Design records are in
[[file:.plans/decisions][.plans/decisions]], in the repository but not in release archives.

=make bench= times jsonparse against [[https://github.com/lloyd/yajl][yajl]] and eleven other JSON parsers on
eight test files, five public and three generated, and writes
=build/bench/report.md=. Run it on the host: it downloads the public files,
then uses the container. Elsewhere it needs a C compiler, =pkg-config= and
yajl, such as Homebrew's, and =BENCH_PARSERS= names the other parsers
installed. =make bench-callbacks=, also run on the host, splits what
jsonparse's callbacks cost a value between byte-machine, the handler's own
work and jsonparse, into =build/bench/callbacks.md=.
