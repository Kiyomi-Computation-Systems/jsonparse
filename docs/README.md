# jsonparse

A fast, strict JSON parser for R6RS Scheme. It reads JSON into plain Scheme
values and writes them back out. Its parser is generated by
[byte-machine](https://github.com/Kiyomi-Computation-Systems/byte-machine).

💡 These pages are Markdown in the repository's [docs](../docs) directory.

## A taste

```scheme
(import (rnrs) (jsonparse easy))

(define v (string->json "{\"name\": \"Ada\", \"langs\": [\"en\", \"fr\"]}"))
v                                        ; => (("name" . "Ada") ("langs" . #("en" "fr")))
(json-ref v "langs" 1)                   ; => "fr"
(json->string '(("ok" . #t) ("n" . 1.5)))  ; => "{\"ok\":true,\"n\":1.5}"

(guard (e ((json-error? e) (list (json-error-reason e) (json-error-offset e))))
  (string->json "{\"a\": tru}"))
;; => (unexpected-byte 9)
```

[Installing](installing.md) says how to get it: from a checkout now, and soon
with Akku. In a checkout, `make dev` starts a REPL to type these lines into.

## Ideas to keep in mind

- **Values are plain Scheme.** An object is an alist, an array a vector,
  `null` the symbol `null`. A hashtable or another `null` is an option away.
- **Strict.** Input that isn't RFC 8259 JSON is refused, with a reason, such
  as `unexpected-byte`, and an offset that says where. `(jsonparse easy)`
  raises them as a `&json-error`.
- **Bytes can arrive in pieces.** The lower layers take input split
  anywhere, even inside a number, and give the same answer.
- **Streams of values too:** JSON Lines, RFC 7464 records, or values with
  whitespace between them.
- **Numbers keep their meaning.** An integer reads as an exact integer, and
  other numbers as flonums. Ask for `exact` or `text` to keep every digit.

## What's in it

| Library                | What it gives you                                                |
|:-----------------------|:-----------------------------------------------------------------|
| `(jsonparse easy)`     | `string->json`, `json->string`, `json-ref`: whole documents and streams |
| `(jsonparse tree)`     | a builder that turns bytes fed in pieces into values             |
| `(jsonparse writer)`   | `put-json`: values to a binary port                              |
| `(jsonparse sequence)` | a reader for a stream of many values, fed in pieces              |
| `(jsonparse parser)`   | the push parser: bytes in, calls to your procedures out          |
| `(jsonparse string)`   | joins a string's or a number's parts, and converts numbers       |
| `(jsonparse options)`  | `make-json-options`, which every layer takes                     |
| `(jsonparse error)`    | `&json-error` and `&json-record-error`                           |

Most programs need only `(jsonparse easy)`.

## What it is not

- **No textual ports.** Pass a binary port, or a string or a bytevector.
- **No Windows.** Linux and macOS, on x86-64 and arm64.
